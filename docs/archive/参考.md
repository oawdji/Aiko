### 📄 论文与项目清单

**REMT — 记忆拓扑与情绪图结构**
*   **论文标题**：*From simulated empathy to structural attunement: Realtime Editable Memory Topology and the evolution of emotionally grounded AI*
*   **核心内容**：将自传体记忆组织为情绪效价节点构成的动态图，通过边强化、衰减与修剪模拟“合成神经可塑性”，并引入有界的 Mood Index 调节检索偏差与回复生成。
*   **链接**：Frontiers 全文 → `https://www.frontiersin.org/journals/artificial-intelligence/articles/10.3389/frai.2026.1749517/full`

**ZifaMem — 结构化情感长期记忆**
*   **论文标题**：*ZifaMem: Structured Memory for Persona, Preference, and Emotional Continuity in AI Companions*
*   **核心内容**：将会话组织为 session summaries、episodic memories 和 consolidated user model 三层；关键发现是，当结构化记忆已存在时，额外增加独立情绪状态机并无 measurable 增益。
*   **链接**：arXiv → `https://arxiv.org/abs/2607.17564`｜开源 SDK → `https://github.com/zifacorp/zifamem`

**AURA-X Ω — 双记忆共振与情绪连续性**
*   **论文标题**：*AURA-X Ω: An Artificial Unified Resonance Architecture for Emotional Continuity and Human–AI Affective Integration*
*   **核心内容**：通过 Temporary Memory (TM) 与 Bold Memory (BM) 的双记忆共振引擎建模情绪连续性，将情绪定义为两层记忆共振的结果，并受衰减/扰动等因素调制。
*   **链接**：Zenodo → `https://zenodo.org/records/17955647`

**cogmem-agent — 唤醒度门控记忆与自适应遗忘**
*   **核心内容**：每条记忆携带唤醒度分数（0.0–1.0），高唤醒事件优先写入并持久保留；遗忘采用自适应半衰期：`half_life = base_half_life × (1 + arousal)`。其学术版本为 CogMem 认知图架构。
*   **链接**：PyPI → `https://pypi.org/project/cogmem-agent/`｜CogMem 论文（OpenReview）→ `https://openreview.net/`（搜索 "CogMem Evolvable Cognitive Memory"）

**feltstate — 可审计的情感记忆衰减与遗忘生命周期**
*   **核心内容**：持久情感在回复模型之外独立评估，记忆是衰减的 5W1H 事实库；显著性按时间线性衰减，被重复强化或召回时“充值”，低于阈值进入归档或真正遗忘。
*   **链接**：GitHub → `https://github.com/agent-memory-atlas-archive/Morephine--feltstate`

**MATE — 确定性情感中间件**
*   **论文标题**：*MATE: A Deterministic Affective Middleware for LLM-Based Companions with Emergent Character and Persistent Internal State*
*   **核心内容**：纯函数 `transition(state, event) → new_state`，零 LLM 调用、完全可复现；集成量子概率形式、双过程习惯化、7 维记忆图等模块，为 LLM 提供持久内部状态。
*   **链接**：Zenodo → `https://zenodo.org/records/20400530`

**EmoClaw — 轻量 GRU 情感引擎与时间指数衰减**
*   **核心内容**：基于 GRU 的时序情感引擎，覆盖愉悦度、唤醒度、信任度等多维情绪；离线/间隔对话时情绪按可配置半衰期自然回落基线（唤醒度衰减快，安全感/踏实感衰减慢）。
*   **链接**：GitHub 技能页 → `https://github.com/`（搜索 "EmoClaw Emotion Skill"）

**CTEM — 跨时序情感建模**
*   **论文标题**：*Toward Natural and Companionable Virtual Agents via Cross-Temporal Emotional Modeling*
*   **核心内容**：将长期行为历史与 moment-to-moment 的情绪表达相连接；过去经验更新情绪状态，情绪状态条件化当前交互，用户反馈同时修正记忆与情绪状态，形成闭环。
*   **链接**：arXiv → `https://arxiv.org/abs/2605.15812`

**Drivesoid — 16 维心理驱力与快慢情绪分离**
*   **核心内容**：追踪 16 个心理维度（依恋、威胁、奖励等），区分快变情绪（base）与慢变心境（mood）；剧烈事件通过唤醒度门控优先固化进 mood，mood 再以“天”为尺度回归性情锚点。
*   **链接**：GitHub → `https://github.com/A1batr055/Drivesoid`

**MiAgent — 多模态情感识别中的跨模态分歧处理**
*   **论文标题**：*From disagreement to insight: multi-agent collaborative reasoning for multimodal emotional support conversations*
*   **核心内容**：专用 video/audio/text 多智能体独立分析情绪，并引入 affective reasoning agent 专门处理跨模态分歧（如“言语—非言语解离”），而非简单平均融合。
*   **链接**：ACM DL（Multimedia Systems）→ `https://dl.acm.org/doi/`（搜索标题）

**EmoLoom-2B — 轻量 VAD 联合预测与情感分类**
*   **论文标题**：*EmoLoom-2B: Fast Base-Model Screening for Emotion Classification and VAD with Lexicon-Weak Supervision and KV-Off Evaluation*
*   **核心内容**：轻量级模型，同时进行情绪分类与 Valence–Arousal–Dominance 预测，采用词典弱监督与 KV-Off 评估，适合作为文本侧 VAD 估计的快速基线。
*   **链接**：arXiv → `https://arxiv.org/abs/2601.01112`
